# MOV / MP4 File Integrity Checker

This tool checks whether video files (.mov, .mp4, etc.) are damaged or incomplete:

* Whether the file is valid
* Whether it is corrupted
* How much of the video is still playable
* Where the corruption occurs
* Why the file may have failed

If the file is corrupted, it also creates a visual report.
